# Reporting a Vulnerability

> **Do not file security issues in public.** Public issues create a window
> of exposure before a fix is available.

Until a formal program is published, please report vulnerabilities to the
project owner via the contact listed in the GitHub repository's profile.
Include:

1. A clear description of the issue and its impact.
2. Steps to reproduce, including affected version / commit.
3. Any relevant logs or proof-of-concept (redact secrets).
4. Your preferred contact for follow-up.

We will acknowledge receipt within a reasonable time and coordinate on a
fix and disclosure. Please give us a chance to remediate before any public
disclosure.

We will document a formal coordinated-disclosure policy and PGP contact
before the first public release.
